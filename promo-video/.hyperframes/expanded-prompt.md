# ECHOFORM — Let a voice become a place

32s, 1920x1080, 30fps. Intended for the user's X post.
The user has authorized creating this companion film; use the established ECHOFORM identity.
Palette and fonts are defined in ../design.md.
Rhythm: HOOK — GROW — CRYSTAL / MACHINE / ORGANIC — EXPLORE — INVITE.
Motion: restrained cinematic dissolves, 0.55s; three-direction typographic entrances.
All motion must be seekable; video and original soundtrack use separate media tracks.

## 0–4 seconds: Invitation
Concept: the building exists as light before it has walls.
Use a luminous core from the real crystal render behind a dark atmospheric veil.
Headline: 让声音，成为建筑. English: A VOICE BECOMES A PLACE.
ECHOFORM wordmark, thin gold orbit, registration corners and waveform create depth.
Headline rises 45px, wordmark resolves from blur, rule draws horizontally.
Model attribution appears below the title, without claiming an API runs in the browser.
Transition: 0.6s soft dissolve into the actual architecture growing.

## 4–11 seconds: Sound becomes structure
Actual geometry grows on the application's time axis, accelerated editorially.
Headline: 一句话，长出一座空间.
Supporting text: 音高成拱 · 节奏成梯 · 停顿成空厅.
BG: actual particle field and camera orbit; MG: architecture; FG: readable caption panel.
Entrance: label slides from left, headline lifts, audio trace draws in gold.
Transition: crystal image resolves through a 0.55s dissolve.

## 11–15 seconds: Crystal
Actual crystal building on an external orbit. Warm gold and pale glass.
Label 01 / CRYSTAL SANCTUM; title 水晶圣殿.
Bottom text: 同一段声音，三种建筑语言.
Fine orbit mark drifts; title enters from left and subline from below.
Transition: dissolve 0.55s, keeping building as focal point.

## 15–19 seconds: Machine
Actual mechanical geometry, cyan signal light, different camera angle.
Label 02 / NEO MACHINE; title 未来机械.
Precise, slightly faster text reveal; cyan rule and moving ticks.
Transition: soft dissolve 0.55s.

## 19–23 seconds: Organic
Actual organic geometry with coral accents and slow camera.
Label 03 / FLUID ORGANIC; title 流体有机.
Calmer curved pulse, title resolves from a shallow blur.
Transition: 0.55s into a walk-through camera shot.

## 23–27 seconds: Enter and take away
Move through the actual architecture, showing depth and interior detail.
Headline: 走进去，也带走它.
Supporting text: 自由漫游 / 海报与视频导出 / 音频全程本地处理.
Readable feature chips reveal with a short stagger; no raw dashboard-sized UI.
Transition: slow 0.7s dissolve toward closing invitation.

## 27–32 seconds: Open source
Actual architecture remains behind dark veil, as a quiet living backdrop.
Large ECHOFORM, Chinese 声音建筑师, badge OPEN SOURCE · MIT.
Clear credit: 建模与初版代码 · DeepSeek V4.1 Flash 1017.
CTA: 说一句话，建一座只属于你的建筑.
Live URL and GitHub repository large enough to read on mobile.
Final 0.6s picture and audio fade; no new visual information in the last second.

Negative direction: no flat slide deck, tiny text, random neon, unrelated architecture,
no AI video generation pretending to be application footage, no premature text exits.
